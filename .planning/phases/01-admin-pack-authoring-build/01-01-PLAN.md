    API — DATABASE CLIENT (`api/src/db/client.ts`):
    Import `'dotenv/config'`, create a `postgres` client from `process.env.DATABASE_URL`

    export `db` and `sql`. This is the only place a connection is opened.

    API — AUTH (`api/src/middleware/adminAuth.ts`, D-01):
    Export `adminAuthPreHandler(req, reply)`. Read `process.env.ADMIN_API_TOKEN`; if it is unset
    or empty, reply 500 with `{ error: 'ADMIN_API_TOKEN not configured' }` — never fall through
    to an open route. Read the `authorization` header; when absent or not starting with
    `Bearer `, reply 401 `{ error: 'Unauthorized' }`. Compare the presented token to the expected
    one with `timingSafeEqual` from `node:crypto` over `Buffer.from(...)` values, guarding the
    unequal-length case first (`timingSafeEqual` throws on mismatched lengths); on mismatch reply
    403 `{ error: 'Forbidden' }`. Return without replying on success.

    API — ADMIN PLUGIN (`api/src/routes/admin/index.ts`):
    Export `registerAdminRoutes(fastify)`. Inside it call `fastify.addHook('preHandler',
    adminAuthPreHandler)` once, then register `registerPackRoutes` and `registerFieldRoutes`.
    Every admin route module is registered here and nowhere else, so no module can be mounted
    outside the authenticated scope.

    API — PACK ROUTES (`api/src/routes/admin/packs.ts`):
    Define `CreatePackSchema` with Zod: `name` (min 1), `slug` (regex `^[a-z0-9][a-z0-9-]{0,62}$`),
    `description` optional, `packType` enum `['standard','state']`, `poiTypeId` optional uuid,
    `stateCode` optional 2-char, `appleProductId` (min 1), `priceTier` optional. Export
    `registerPackRoutes(fastify)` mounting:
      - `POST /v1/admin/packs` — parse the body with `CreatePackSchema`, on a Zod failure reply
        400 `{ error: 'VALIDATION_FAILED', issues: <flattened zod issues> }`; insert into `packs`
        via Drizzle `.returning()`; on the Postgres unique-violation code `23505` reply 409
        `{ error: 'SLUG_OR_PRODUCT_ID_TAKEN' }`; otherwise reply 201 with the inserted row.
      - `GET /v1/admin/packs` — select all packs ordered by `createdAt` descending, reply 200 with an array.
      - `GET /v1/admin/packs/:id` — select one pack plus its `packFieldDefinitions` rows ordered
        by `sortOrder` then `fieldKey`, reply 200 `{ pack, fields }` or 404 `{ error: 'PACK_NOT_FOUND' }`.
    Use only the Drizzle query builder — no string-interpolated SQL anywhere.

    API — FRAMEWORK FIELD ROUTE (`api/src/routes/admin/fields.ts`, ADMINFW-01):

    also blocks object keys that would be dangerous once the value is stored as a JSONB key on
    `pois.custom_fields`), `label` (min 1), `dataType` enum

    `registerFieldRoutes(fastify)` mounting `POST /v1/admin/packs/:id/framework/fields`: validate,
    confirm the pack exists (404 `PACK_NOT_FOUND` otherwise), insert into `packFieldDefinitions`,
    map Postgres `23505` to 409 `{ error: 'FIELD_KEY_TAKEN' }`, reply 201 with the row.
